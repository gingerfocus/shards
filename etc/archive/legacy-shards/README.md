# Archived Shards source

This directory was the repository-root `shards/` tree. It contains earlier
`builtins/` and `env/` source files, including Rust and C++ fragments. It has
no Cargo manifest and is not a member of the workspace.

The active Shards runtime is `crates/shards/`; the executable is
`crates/shardscli/`. Keep this tree as reference material when porting
individual builtins or environment behavior.
